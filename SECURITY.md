# Security policy

## Supported version

Security fixes are made for the latest version on the default branch.

## Reporting a vulnerability

Please do not publish credentials, proof-of-concept payloads, or exploit details in a public issue. Use GitHub private vulnerability reporting when it is enabled for this repository; otherwise contact the repository maintainer privately through the account linked from the repository.

Include the affected version, reproduction steps, expected and actual behavior, and any relevant configuration preconditions. A report is acknowledged after review; fixes are released before public disclosure whenever practical.
